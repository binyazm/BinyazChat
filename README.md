
# 💙 BINYAZ CHAT

پیام‌رسان آنلاین با رابط فارسی و راست‌چین، طراحی واکنش‌گرا و قابلیت نصب روی گوشی.

## ✨ امکانات

- ورود و ثبت‌نام با ایمیل
- جست‌وجوی کاربران با نام کاربری
- گفت‌وگوی خصوصی
- ارسال و دریافت پیام با قابلیت به‌روزرسانی لحظه‌ای
- ویرایش نام نمایشی پروفایل
- رابط کاربری سازگار با موبایل و دسکتاپ
- پشتیبانی اولیه از نصب به‌صورت PWA

## 🛠 فناوری‌ها

- HTML
- CSS
- JavaScript
- Supabase Auth
- Supabase Database و Realtime
- Service Worker

## 📁 فایل‌های پروژه

- `index.html` — صفحهٔ اصلی
- `styles.css` — طراحی و ظاهر برنامه
- `app.js` — منطق برنامه و اتصال به Supabase
- `manifest.webmanifest` — تنظیمات نصب برنامه
- `sw.js` — سرویس‌ورکر
- `icon-192.png` — آیکون ۱۹۲ پیکسلی
- `icon-512.png` — آیکون ۵۱۲ پیکسلی

## 🚀 راه‌اندازی

۱. پروژه را در GitHub قرار بده.

۲. در تنظیمات Supabase، احراز هویت، جدول‌ها، سیاست‌های امنیتی RLS و Realtime را مطابق ساختار برنامه تنظیم کن.

۳. از بخش Settings → Pages در GitHub، گزینهٔ انتشار از شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب کن.

۴. پس از انتشار، آدرس GitHub Pages را با Chrome باز کن.

۵. برای نصب روی اندروید، منوی Chrome را باز کن و گزینهٔ نصب برنامه یا افزودن به صفحهٔ اصلی را انتخاب کن.

## 🔐 امنیت

- کلیدهای محرمانهٔ Supabase را در کد سمت مرورگر قرار نده.
- فقط از کلید عمومی Publishable/Anon در برنامهٔ سمت کاربر استفاده کن.
- دسترسی به داده‌ها باید با سیاست‌های RLS محدود شود.
- پیش از استفادهٔ واقعی، امنیت ثبت‌نام، پروفایل‌ها، گفت‌وگوها و پیام‌ها را آزمایش کن.

## 📌 وضعیت

نسخهٔ اولیه؛ پیش از استفادهٔ عمومی باید اتصال پایگاه داده، مجوزها و عملکرد برنامه آزمایش شوند.
